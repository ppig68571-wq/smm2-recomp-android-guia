# Vulkan shim

Este código fuente auxiliar permite integrar AdrenoTools en el build Android descrito por esta guía. El driver Turnip binario se obtiene por separado y no forma parte del repositorio.

Revisa primero las instrucciones actuales de `vulkan-shim/README.md` y compila solo para tu propio dispositivo. La compatibilidad en teléfonos físicos no está validada por upstream.
